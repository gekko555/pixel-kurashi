# テスト設計書

## テストの目的
- バグの早期発見
- 仕様変更時の回帰テスト
- コードの品質保証

## テスト対象と観点

### 1. Controllerテスト（APIエンドポイント）

**確認項目:**
- 正常なリクエストで正しいレスポンスが返るか
- バリデーションエラー時に適切なエラーレスポンスが返るか
- HTTPステータスコードが正しいか
- レスポンスのJSON形式が正しいか

**テストケース:**
- GET /api/money-records（正常系）
  - 200 OKが返るか
  - レスポンスに家計簿記録のリストが含まれるか
  - 各フィールド（id, recordDate, amount, category, memo）が正しいか

- POST /api/money-records（正常系）
  - 200 OKが返るか
  - 正常なデータで登録が成功するか

- POST /api/money-records（異常系: バリデーションエラー）
  - 400 Bad Requestが返るか
  - 日付がnullの場合にエラーになるか
  - 金額がnullの場合にエラーになるか
  - カテゴリが空文字の場合にエラーになるか

- PUT /api/money-records/{id}（正常系）
  - 200 OKが返るか
  - 正常なデータで更新が成功するか

- PUT /api/money-records/{id}（異常系: バリデーションエラー）
  - 400 Bad Requestが返るか
  - 日付がnullの場合にエラーになるか
  - 金額がnullの場合にエラーになるか
  - カテゴリが空文字の場合にエラーになるか

- DELETE /api/money-records/{id}（正常系）
  - 200 OKが返るか
  - 正常なIDで削除が成功するか

- GET /api/money-records/month/{year}/{month}（正常系）
  - 200 OKが返るか
  - 指定した月の記録のみが返るか

- GET /api/money-records/day/{date}（正常系）
  - 200 OKが返るか
  - 指定した日の記録のみが返るか

### 2. Serviceテスト（ビジネスロジック）

**確認項目:**
- DTO → Entity変換が正しく行われるか
- Entity → DTO変換が正しく行われるか
- Repositoryのメソッドが正しく呼び出されるか

**テストケース:**
- toEntityメソッド
  - MoneyRecordCreateRequestの各フィールドがMoneyRecordに正しくコピーされるか
  - recordDate, amount, category, memoが正しいか

- toResponseメソッド
  - MoneyRecordの各フィールドがMoneyRecordResponseに正しくコピーされるか
  - id, recordDate, amount, category, memo, createdAt, updatedAtが正しいか

- createRecordメソッド
  - repository.insert()が正しく呼び出されるか
  - 引数が正しいEntityであるか

### 3. Repositoryテスト（データアクセス）

**確認項目:**
- INSERTが正しく実行されるか
- SELECTが正しく実行されるか
- SQLが正しく実行されるか

**テストケース:**
- insertメソッド
  - データが正しくDBに保存されるか
  - 自動採番されたIDが取得できるか

- findAllメソッド
  - 全件取得が正しく行われるか
  - レコード数が正しいか
  - 各フィールドが正しく取得できるか

## テストツール
- JUnit 5
- Mockito
- Spring Boot Test
- MockMvc（Controllerテスト用）

## テスト実行方法
```bash
# 全テスト実行
mvn test

# 特定のテストクラス実行
mvn test -Dtest=MoneyRecordControllerTest

# 特定のテストメソッド実行
mvn test -Dtest=MoneyRecordControllerTest#testGetAllRecords
```

## テスト依存

**pom.xmlに追加**:
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-test</artifactId>
    <scope>test</scope>
</dependency>
```
