# 01_プロジェクト概要
| 項目 | 内容 |
| --- | --- |
| プロジェクト名 | 生活育成型家計簿アプリ |
| 開発方針 | 小さく作る→画面確認→改善（アジャイル） |
| 技術 | Spring Boot + React(TypeScript) + MySQL + Docker + AWS + CI/CD + Canvas API/Phaser.js |
| 初期スコープ | 家計簿のINSERT/SELECT |
| 将来スコープ | pt/キャラ/レベル/部屋/アニメ/写真ドット絵化/ミニゲーム/モバイルアプリ |
| 運用 | 各Phase完了ごとに設計書更新 |


# 02_開発フロー
| No | フロー | 目的 | 成果物 |
| --- | --- | --- | --- |
| 1 | 1機能に絞って要件化 | スコープ肥大防止 | 完了条件 |
| 2 | 画面→API→DBを縦実装 | 毎回動く状態 | 動作する機能 |
| 3 | 手動テスト | 品質確認 | テスト結果 |
| 4 | 設計更新 | 改善の蓄積 | 次回改善欄 |

# 06_DB全体像
| テーブル | 用途 | 初心者向け説明 |
| --- | --- | --- |
| app_user | ユーザー | ログインユーザー。username+BCryptパスワード |
| money_record | 家計簿 | 最初に必須。収支を保存（user_idでユーザー紐付け） |
| category_master | カテゴリマスタ | カテゴリの定義（食費、交通費など） |
| sub_category_master | サブカテゴリマスタ | サブカテゴリの定義（外食、スーパーなど） |
| point_balance | ポイント残高 | 合計ptを高速表示 |
| point_history | ポイント履歴 | なぜ加点/減点されたかを残す |
| character_state | キャラ状態 | 見た目・レベル・行動を管理 |
| level_rule | レベル条件 | 必要ptの定義 |
| schedule_rule | 時間帯ルール | 朝昼夜や平日/休日を定義 |
| furniture_master | 家具マスタ | 購入可能家具の定義 |
| user_furniture | 所持家具 | 購入済み家具 |
| animation_profile | アニメ設定 | fpsなど表示速度 |
| avatar_source | 画像管理 | 元画像とドット絵画像 |
