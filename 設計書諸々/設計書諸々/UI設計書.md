# 01_UI全体方針
| 項目 | 内容 |
| --- | --- |
| コンセプト | 家計簿をつけてポイントを貯め、ドット絵キャラとお部屋を育てる |
| デザインテイスト | ドット絵・2.5頭身キャラ・温かみのあるベージュ基調 |
| ターゲット | 20代前後の家計簿初心者 |
| UIフレームワーク | React + TailwindCSS |
| アイコン | Lucide |

# 03_画面一覧
| 画面ID | 画面名 | 概要 | 主要機能 |
| --- | --- | --- | --- |
| SCR-000A | ログイン | ログインフォーム | username/password入力・ログイン |
| SCR-000B | 新規登録 | ユーザー作成フォーム | username/password入力・登録 |
| SCR-001 | ホーム | キャラ・お部屋・収支サマリ表示 | レベル/pt/今月収支/タスク |
| SCR-002 | 家計簿をつける | 収支入力フォーム | 収入支出/日付/カテゴリ/金額/メモ |
| SCR-003 | 家計簿一覧 | 登録済み記録の一覧 | 一覧/編集/削除 |
| SCR-004 | ショップ | 家具・服の購入 | ptで購入 |
| SCR-005 | 設定 | 各種設定 | プロフィール/通知 |

# 04_ホーム画面（SCR-001）項目定義
| 項目名 | 種別 | 説明 |
| --- | --- | --- |
| レベル表示 | テキスト | Lv.12 など |
| ポイント表示 | テキスト | 1,245 pt |
| キャラクター | 画像（ドット絵） | 時間帯/状態でアニメーション |
| お部屋 | 画像（ドット絵） | レベルで内装が変化 |
| 吹き出し | テキスト | 「今日も頑張ったね！」など |
| 収支達成率 | プログレスバー | 今月の達成率（80%など） |
| 今月の収支 | テキスト | +25,300円 |
| 今日のタスク | チェックリスト | ログイン/家計簿/目標 各+1pt |
| ナビゲーション | タブバー | ホーム/家計簿/ショップ/設定 |

# 05_家計簿入力画面（SCR-002）項目定義
| 項目名 | 種別 | 必須 | 説明 |
| --- | --- | --- | --- |
| 収入/支出 | トグルボタン | 必須 | 収入か支出を選択 |
| 日付 | 日付ピッカー | 必須 | 2024/05/15 |
| カテゴリ | セレクト | 必須 | 食費など（カテゴリマスタ連動） |
| 金額 | 数値入力 | 必須 | 1,200円 |
| メモ | テキスト | 任意 | ランチ代など |
| 保存ボタン | ボタン | - | 緑色のCTAボタン |

# 06_共通レイアウト
| 項目 | 内容 |
| --- | --- |
| ヘッダー | 画面タイトル + 戻るボタン |
| フッター | 4タブ固定ナビ（ホーム/家計簿/ショップ/設定） |
| 全体幅 | モバイルファースト（max-width: 480px想定） |
| 余白 | カード間に十分な余白、角丸を多用 |

# 07_キャラクター・お部屋仕様
| 項目 | 内容 |
| --- | --- |
| 頭身 | 2.5頭身ドット絵 |
| 性別 | 男性/女性 選択可 |
| アニメーション | 待機（まばたき）/歩く/喜ぶ/考える/スマホを見る |
| 部屋レベル | Lv.1（はじまりの部屋）→Lv.5（くつろぎの部屋）→Lv.10（理想の部屋） |
| カスタマイズ | 家具・インテリア・服・ヘアスタイルを変更可能 |
