



# 詳細なデータフロー（変数レベル）

## 1. INSERT（新規登録）

### ステップ1: ユーザー入力 → 変数に格納

```
ユーザーが「日付」入力欄に「2026-06-21」と入力
    ↓ onChangeイベント発火
onChange={(e) => setFormData({...formData, recordDate: e.target.value})}
    ↓ e.target.value = "2026-06-21"
setFormData({...formData, recordDate: "2026-06-21"})
    ↓ formData変数が更新
formData = {
    recordDate: "2026-06-21",
    amount: 0,
    categoryId: 0,
    memo: ''
}
```

```
ユーザーが「金額」入力欄に「1500」と入力
    ↓ onChangeイベント発火
onChange={(e) => setFormData({ ...formData, amount: Number(e.target.value) })}
    ↓ e.target.value = "1500"
    ↓ Number("1500") = 1500
setFormData({ ...formData, amount: 1500 })
    ↓ formData変数が更新
formData = {
    recordDate: "2026-06-21",
    amount: 1500,
    categoryId: 0,
    memo: ''
}
```

```
ユーザーが「カテゴリ」選択欄で「食費（id=1）」を選択
    ↓ onChangeイベント発火
onChange={(e) => setFormData({ ...formData, categoryId: Number(e.target.value) })}
    ↓ e.target.value = "1"
    ↓ Number("1") = 1
setFormData({ ...formData, categoryId: 1 })
    ↓ formData変数が更新
formData = {
    recordDate: "2026-06-21",
    amount: 1500,
    categoryId: 1,
    memo: ''
}
```

```
ユーザーが「メモ」入力欄に「ランチ」と入力
    ↓ onChangeイベント発火
onChange={(e) => setFormData({ ...formData, memo: e.target.value })}
    ↓ e.target.value = "ランチ"
setFormData({ ...formData, memo: "ランチ" })
    ↓ formData変数が更新
formData = {
    recordDate: "2026-06-21",
    amount: 1500,
    categoryId: 1,
    memo: "ランチ"
}
```

### ステップ2: フォーム送信 → handleSubmitハンドラー

```
ユーザーが「登録」ボタンをクリック
    ↓ onSubmitイベント発火
<form onSubmit={handleSubmit}>
    ↓ handleSubmit関数が呼び出される
handleSubmit(e)
    ↓ e.preventDefault()でデフォルトのフォーム送信をキャンセル
    ↓ tryブロック開始
```

### ステップ3: createMoneyRecord関数呼び出し

```
await createMoneyRecord(formData)
    ↓ formData引数に値を渡す
formData = {
    recordDate: "2026-06-21",
    amount: 1500,
    categoryId: 1,
    memo: "ランチ"
}
    ↓ api/moneyRecords.tsのcreateMoneyRecord関数へ
createMoneyRecord(data)
    ↓ data引数にformDataの値が入る
data = {
    recordDate: "2026-06-21",
    amount: 1500,
    categoryId: 1,
    memo: "ランチ"
}
```

### ステップ4: fetchリクエスト

```
const response = await fetch(BASE_URL, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
})
    ↓ JSON.stringify(data)でJavaScriptオブジェクトをJSON文字列に変換
JSON.stringify(data) = '{"recordDate":"2026-06-21","amount":1500,"categoryId":1,"memo":"ランチ"}'
    ↓ HTTPリクエスト送信
POST http://localhost:8080/api/money-records
Content-Type: application/json
Body: {"recordDate":"2026-06-21","amount":1500,"categoryId":1,"memo":"ランチ"}
    ↓ response変数にResponseオブジェクトが入る
response = {
    ok: true,
    status: 200,
    statusText: "OK",
    ...
}
```

### ステップ5: assertOkチェック

```
await assertOk(response)
    ↓ assertOk関数にresponseを渡す
assertOk(response)
    ↓ response.okがtrueなのでエラーを投げない
    ↓ 関数終了
```

### ステップ6: 成功処理

```
alert('家計簿の登録が完了しました')
    ↓ アラート表示
setFormData({ recordDate: '', amount: 0, categoryId: 0, memo: '' })
    ↓ formData変数を初期化
formData = {
    recordDate: '',
    amount: 0,
    categoryId: 0,
    memo: ''
}
window.location.reload()
    ↓ ページをリロード
```

## 2. SELECT（全件取得）

### ステップ1: コンポーネントマウント → useEffect

```
MoneyRecordListコンポーネントがマウントされる

useEffect(() => {
    const loadRecords = async () => {
        try {
            const data = await fetchMoneyRecords();
            setRecords(data);
            setLoading(false);

            setLoading(false);
```

## 3. UPDATE（更新）

### ステップ1: ユーザーが「更新」ボタンをクリック

```
ユーザーが「更新」ボタンをクリック
    ↓ onClickイベント発火
<button onClick={() => updateRecord(record)}>更新</button>
    ↓ updateRecord関数が呼び出される
updateRecord(record)
    ↓ record引数に値を渡す
record = {
    id: 1,
    recordDate: "2026-06-21",
    amount: 1500,
    categoryId: 1,
    categoryName: "食費",
    memo: "ランチ",
    createdAt: "2026-06-21T00:00:00",
    updatedAt: "2026-06-21T00:00:00"
}
```

### ステップ2: setEditFormDataで編集フォームを表示

```
setEditFormData({
    id: record.id,
    recordDate: record.recordDate,
    amount: record.amount,
    categoryId: record.categoryId,
    memo: record.memo
})
    ↓ editFormData変数が更新される
editFormData = {
    id: 1,
    recordDate: "2026-06-21",
    amount: 1500,
    categoryId: 1,
    memo: "ランチ"
}
    ↓ 編集フォームが表示される
{editFormData && (
    <div>
        <h3>編集</h3>
        <input type="date" value={editFormData.recordDate} ... />
        <input type="number" value={editFormData.amount} ... />
        <select value={editFormData.categoryId} ... />
        <input type="text" value={editFormData.memo} ... />
        <button onClick={handleUpdate}>保存</button>
        <button onClick={() => setEditFormData(null)}>キャンセル</button>
    </div>
)}
```

### ステップ3: ユーザーが編集

```
ユーザーが「金額」入力欄を「2000」に変更
    ↓ onChangeイベント発火
onChange={(e) => setEditFormData({...editFormData, amount: Number(e.target.value) })}
    ↓ e.target.value = "2000"
    ↓ Number("2000") = 2000
setEditFormData({...editFormData, amount: 2000})
    ↓ editFormData変数が更新される
editFormData = {
    id: 1,
    recordDate: "2026-06-21",
    amount: 2000,
    categoryId: 1,
    memo: "ランチ"
}
```

### ステップ4: ユーザーが「保存」ボタンをクリック

```
ユーザーが「保存」ボタンをクリック
    ↓ onClickイベント発火
<button onClick={handleUpdate}>保存</button>
    ↓ handleUpdate関数が呼び出される
handleUpdate()
    ↓ if (editFormData)でeditFormDataがnullでないことを確認
    ↓ tryブロック開始
```

### ステップ5: updateMoneyRecord関数呼び出し

```

    ↓ editFormData.id = 1
    ↓ editFormData = {
        id: 1,
        recordDate: "2026-06-21",
        amount: 2000,
        categoryId: 1,
        memo: "ランチ"
    }
    ↓ api/moneyRecords.tsのupdateMoneyRecord関数へ
updateMoneyRecord(id, data)
    ↓ id引数に1が入る
    ↓ data引数にeditFormDataの値が入る
id = 1
data = {
    id: 1,
    recordDate: "2026-06-21",
    amount: 2000,
    categoryId: 1,
    memo: "ランチ"
}
```

```
Body: {"id":1,"recordDate":"2026-06-21","amount":2000,"categoryId":1,"memo":"ランチ"}
    ↓ response変数にResponseオブジェクトが入る
response = {
    ok: true,
```
